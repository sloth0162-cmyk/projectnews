# Changelog



### Added

* Added AI image generation for news articles.
* Added password protection for running the news pipeline.
* Added individual article pages.
* Added Supabase Storage for storing article images.

### Fixed

* Fixed homepage UI issues.
* Fixed routing issues.
* Fixed API issues.

### Changed

* Reduced article generation from 6 articles at a time to 3 articles at a time.
* Tag schema from v1 was lost and has not yet been recreated, so tag-based filtering is currently unavailable.
